# Cat by EverestQai

Bring a code selection from VS Code into your Cat agent workspace. Open **Cat** in the Activity Bar to connect your account, open your workspace, or launch Cat-Ship and Cat Computer.

## Connect your account

Choose **Create Account** or **Sign In**. Complete the Cat sign-in flow in your browser and review the request to connect your editor. The extension stores its session in the editor's SecretStorage. Choose **Cat: Show Signed-In Account** to check it, or **Cat: Sign Out of Editor** to end it. Your browser manages its own workspace session.

## Share a code selection

1. Select the lines you want an agent to see.
2. Right-click and choose **Cat: Copy Selection for Cat**. The clipboard includes the file name, line range, language, and selected text.
3. Open your Cat workspace and paste the excerpt into a conversation. Review it before you send it.

The extension reads the text you select when you run the copy command. Your project files stay in your editor. Account access requires an internet connection and a browser on the computer running the editor.
